FAQ

Questions, answered.

Will this bot make things up like AI chatbots do?

No. Unlike generative LLMs, MindChat runs on a 100% deterministic rule engine. When a customer asks about an order or stock, it directly queries your store database. If a record doesn't exist, it reliably prompts for an order number or connects to your human team.

Do I need WhatsApp to use this?

No! WhatsApp is completely optional and excluded by default. MindChat focuses on keeping high-intent shoppers directly on your store with our high-speed, web-native embed widget to maximize checkout conversions.

Which platforms can my agent connect to?

Your agent connects natively to Shopify (via theme app embeds & webhooks), WordPress / WooCommerce, and any custom website (HTML, React, Vue, Next.js) using our single-line async script tag.

Connect Your Storefront

Connect this bot to Shopify, WordPress, or your custom website with zero coding.

🛍️ Shopify Storefront

Paste inside theme.liquid before </body>:

<script src="http://localhost:3000/widget.js" data-server="http://localhost:3000" data-source="Shopify" async></script>
🌐 WordPress / WooCommerce

Add to child theme functions.php:

add_action('wp_footer', function() { echo '<script src="http://localhost:3000/widget.js" data-server="http://localhost:3000" data-source="WordPress"></script>'; });
💻 Custom Website Embed

Universal async script tag:

<script src="http://localhost:3000/widget.js" data-server="http://localhost:3000" data-theme="black" async></script>
